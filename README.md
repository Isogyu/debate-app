# COLD SLEEP（ディベート支援アプリ 休止中ページ）

ディベート支援アプリ（`../debate_app`）の代わりに公開する、ログイン不要の静的サイト。
HTML / CSS / JavaScript だけで動き、API・データベース・サーバー処理は使わない。運用費は0円。

| ページ | 内容 |
|--------|------|
| ホーム | コールドスリープ中のお知らせ。カプセルをノックすると寝言が出る |
| 社会人の備忘録 | 「メモ」（社会人になって学んだこと）と「本棚」（おすすめの本）。検索・タグ絞り込みつき |
| 珍裁判 | 「どうでもいい裁判所」。架空の事件に有罪・無罪を言い渡し、裁判所の判断と比べる |
| ゲーム | 「起こさないで」。眠りを妨げるものをタップで追い払う |

## ファイル

| ファイル | 役割 |
|----------|------|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `notes.js` | **備忘録のメモのデータ** |
| `books.js` | **本棚のデータ** |
| `app.js` | タブ切り替え・ホーム・備忘録の表示 |
| `court.js` | 珍裁判（事件を足すときは `CASES` に追加） |
| `game.js` | ゲーム（敵を足すときは `FOES` に追加） |

## 備忘録を追加する

`notes.js` の配列の先頭に1件追加する。

```js
{
  date: "2026-10-20",
  title: "タイトル",
  tags: ["仕事の進め方"],
  body: `
本文。空行で段落が分かれる。

- 行頭に「- 」で箇条書き
`,
},
```

メモか本が1件増えるごとに、ホームの「技術力チャージ」が3%増える（最大99%）。

## 本棚に本を追加する

`books.js` の配列の先頭に1冊追加する。

```js
{
  title: "書名",
  author: "著者",
  from: "職場の先輩",        // 誰のおすすめか（任意。実名は避ける）
  date: "2026-10-20",
  point: "ひとことで言うと",  // カードに常に表示される
  url: "https://...",        // 紹介ページ（任意。アフィリエイトリンクは使わない）
  tags: ["仕事の進め方"],
  body: `
感想・学んだこと（開くと表示される）
`,
},
```

## 手元で確認する

```bash
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く（`index.html` を直接開くと CSS/JS が読み込まれない場合がある）。

## 公開する（無料）

どれも静的サイトなら無料枠で公開できる。

- **GitHub Pages**: このフォルダをリポジトリに置き、Settings → Pages で公開
- **Cloudflare Pages**: フォルダをドラッグ＆ドロップでアップロード
- **Netlify**: 同上

公開後、旧アプリ（Fly.io）は停止すれば課金が止まる。
